Expense Report Summary API

Upload a CSV of expenses and get back totals, a breakdown by category and an executive summary written by an LLM. Every number is computed in plain Python — the model only writes the narrative, so it can't invent a figure.

FastAPI · PostgreSQL · OpenAI API
API docs (Swagger) Source on GitHub
CSV upload→Validate rows→Totals & outliers (Python)→LLM writes summary→Saved to PostgreSQL
Input CSV Columns: date (YYYY-MM-DD), category, amount, description. Edit freely, or load your own file.
