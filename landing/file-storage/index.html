Private File Storage API

Files are validated (type and magic bytes), stored in a private S3 bucket nobody can read directly, and served only through CloudFront URLs signed with an RSA key and valid for 10 minutes. Upload something and compare the signed link with the same link without its signature.

FastAPI · PostgreSQL · AWS S3 + CloudFront (signed URLs, Origin Access Control)
